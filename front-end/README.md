# M8pulse

Application React en JavaScript.

## Installation

```bash
npm install
```

## Démarrage

```bash
npm start
```

L'application s'ouvrira dans votre navigateur à l'adresse [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

Crée une version optimisée pour la production dans le dossier `build/`.
